# Picture baseline from 2026-10-17

This is the reference set that `tools/validate/run-full.sh` compares against. It was approved by the owner on 2026-10-17.

It starts from the T-066 "before" set (`o017-before-20261016T205125Z`) and replaces some pictures. Each change was made on purpose:

- **Showers:** `geminids-*` and `perseids-*` now come from `o017-t075-after-20261017T032416Z`. Since T-075, the dots sit on their true orbits, computed on the graphics chip, instead of the straight-line blend. The pictures differ only on the arcs next to the Sun.
- **Site pages:** `site-index-*` and `site-assets-*` come from the same capture. They reflect the page changes from T-067, T-068, T-074 and T-076.

The owner accepted the new shower pictures as the reference: "previous version ran ok and this should be better".
