## Components/Codebase Map

**Packages (O-035).** The repository is five npm workspaces under `packages/`, each keeping the old folder shape (`src/`, `data/`, `tools/`, `tests/`). `astraeus` is the engine (core, assets, app, shell, `src/experiences/settingsFields.ts`, `showerChoice.ts`, `src/synthetic/`, core data, importers, engine tests and `licenses/`). `astraeus-demo-apollo11`, `astraeus-demo-showers` and `astraeus-demo-planets` hold each demo's `src/experiences/<demo>/`, `data/`, stories, tools and `credits/`. `astraeus-site` holds the pages, `src/main.tsx`, `vite.config.ts` (builds to the root `dist/`), `public/`, `site/`, `tools/site`, `tools/validate` and `tests/packageBoundaries.test.ts`. The root keeps `vitest.config.ts`, `tsconfig.json`, `eslint.config.js`, `tools/lint/` and `tools/check-engine-alone.mjs`. **The rows below were written before the move: read a path such as `src/core/` as `packages/astraeus/src/core/`, `src/experiences/showers/` or `data/showers/` as under `packages/astraeus-demo-showers/`, `src/experiences/planets/` and `data/planets/` under `packages/astraeus-demo-planets/`, `apollo11` likewise under `packages/astraeus-demo-apollo11/`, and `tools/validate/`, `tools/site/`, `src/main.tsx`, the `.html` pages, `site/` and `public/` under `packages/astraeus-site/`.**
