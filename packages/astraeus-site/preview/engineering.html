An astronomy engine for the web

Astraeus is a TypeScript library for building 3D solar-system scenes in the browser. It handles the parts that are easy to get wrong: time scales, orbits, reference frames, and distances that run from a moon's surface to the edge of the planets. Every position it returns says where it came from and how closely it has been checked.

Read the guide API reference Or open a demo ↓

npm install astraeus · version 0.10.1 · the example app's first download is about 526 KB gzipped

runs in Node or the browserMIT
import { Scene, earth, moon } from "astraeus";

// Where was the Moon when Eagle landed?
const when = "1969-07-20T20:17:40Z";
const scene = new Scene()
  .addBody(earth).addBody(moon).setTime(when);
await scene.load();

scene.stateOf("moon", when);
// { center: "earth", plane: "EQJ",
//   positionKm: [-385274.5, -47903.7, -30878.0] }

scene.provenanceOf("moon").accuracy;
// "Measured against eight JPL Horizons (DE441)
//  vectors ... at most 6.4 km in distance ..."

How positions are stored

The engine does not keep a table of positions. For the planets and moons it keeps short polynomial fits to JPL Horizons and evaluates them at any moment. Move the slider to see a two-day stretch of Io's orbit stored both ways.

Hour 0.0 · Io is 421,000 km from Jupiter's centre

  • 47×smaller than the 10-minute table for Io, 2010 to 2030 (1.1 MB against 50.5 MB)
  • 4 cmIo's largest difference from Horizons
  • 6×smaller planet positions (0.21 MB against 1.4 MB), 1969 to 2045
  • 458moons in the six optional data packages, fetched by year as needed

What the engine covers

A planet, a spacecraft, a comet and twenty-five thousand meteoroids go through the same four layers, so one scene can hold all of them.

  1. 01 · STATE

    Time and frames

    UTC, TT and TDB converted in one place. Positions held in J2000 equatorial and converted for drawing.

    UTC·TT·TDBJ2000provenance
  2. 02 · SOURCES

    Data sources

    Horizons fits for planets and moons, orbital elements for comets, asteroids and meteoroids, sampled paths for spacecraft. Each can be swapped on its own.

    JPL HorizonsKeplercatalogues
  3. 03 · DRAWING

    Drawing at any scale

    True or enlarged scale, a floating origin, orbit lines, labels, lighting, and 8,920 naked-eye stars from the HYG catalogue.

    floating originmarkerssky
  4. 04 · STORY

    Timelines and panels

    Playback with events, focus and follow, story panels that open at their moment, and an info card that marks each value observed, modelled or illustrative.

Getting started

Astraeus is on npm. It needs a bundler; Vite 8, webpack 5 and Parcel 2 have each been built and run with the packed package.

  1. 01

    Install

    npm install astraeus react react-dom @react-three/fiber three

    React, React DOM, react-three-fiber and three are peer dependencies, needed even on a plain-JavaScript page.

  2. 02

    Mount a scene

    mount(document.getElementById("app"),
  new Scene().addBody(earth)
    .addBody(moon, { orbit: true }));

    You get time controls, camera, scale and body cards with no 3D code of your own.

  3. 03

    Start from an example

    Four small apps in the repository: hello-scene, hello-react, hello-planets and hello-sky.
