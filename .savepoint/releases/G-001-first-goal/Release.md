Prove the boundary between what the universe is doing and how Astraeus draws it before building a wider engine.

Seek a timestamp, observe credible lunar motion, advance and pause time, switch true/compressed distances, rotate and zoom independently, and reproduce exactly the same scientific state across visual scales. Deliver the small core, automated tests and the short implemented-design note.

## Boundaries

Preserve visual quality, keep physical properties independent of presentation, evaluate an existing astronomy library, and avoid the wider architecture and publishing work excluded by the owner. First step is the plan; implementation follows owner review.
